# 🤝 RightGift P2P Guarantee Bot

Telegram-бот для безопасных P2P-сделок с использованием внутреннего баланса. Подходит для торговли любыми цифровыми активами (подарки, NFT, криптовалюта, фиат) с автоматическим подтверждением оплаты и системой рефералов.

> 💡 **Особенность:** Бот выступает гарантом — покупатель оплачивает сделку со своего баланса, средства блокируются до подтверждения, после чего продавец получает оплату, а покупатель — товар. Всё происходит внутри бота без риска мошенничества.

---

## ✨ Возможности

- **P2P-сделки** – продавец создаёт сделку с указанием суммы, описания и своего кошелька для оплаты. Покупатель переходит по ссылке, видит детали и оплачивает со своего баланса.
- **Внутренний баланс** – у каждого пользователя есть баланс в выбранной валюте (по умолчанию TON). Администраторы имеют бесконечный баланс для тестирования.
- **Управление кошельком** – пользователи могут добавлять или изменять адрес кошелька (реквизиты для оплаты).
- **Статистика продавца** – отображается количество успешных сделок продавца, что повышает доверие.
- **Реферальная программа** – каждый пользователь получает реферальную ссылку (пока без подсчёта, но с бонусами в будущем).
- **Многоязычность** – поддержка русского и английского языков (переключение через меню).
- **Админ-панель**:
  - Просмотр всех активных сделок.
  - Изменение баланса любого пользователя.
  - Изменение количества успешных сделок пользователя.
  - Смена валюты (глобально для всех).
  - Управление списком администраторов (добавление/удаление).
- **Логирование** – все действия и ошибки записываются в файл `bot.log`.
- **База данных SQLite** – сохраняет пользователей, сделки и администраторов.

## 🛠 Технологии

- Python 3.8+

## 🚀 Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/RusGheast/telegram-ots.git
   ```
   ```bash
   cd telegram-ots
   ```
   
Создайте виртуальное окружение и активируйте его

```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
```

Установите зависимости

```bash
pip install python-telegram-bot
```

Получите токен бота

Напишите @BotFather в Telegram, создайте бота и получите токен.

Настройте переменные окружения (рекомендуется)
Создайте в корне файл .env (или просто пропишите токен в коде, но это небезопасно):

```env
BOT_TOKEN=ваш_токен_бота
Либо отредактируйте переменную BOT_TOKEN в bot.py (строка 27).
```

Запустите бота

```bash
python bot.py
```

При первом запуске автоматически создадутся таблицы в bot_data.db и добавится первый администратор с ID 1805496851 (задано в коде). Вы можете изменить этот ID в строке cursor.execute('INSERT OR IGNORE INTO admins (user_id) VALUES (?)', (1805496851,)).

🧑‍💻 Как использовать

Для пользователей

/start – главное меню.

«Добавить/изменить кошелёк» – бот запросит текст (адрес кошелька). Сохраняется в профиле.

«Создать сделку» – продавец вводит сумму, затем описание товара. Бот генерирует уникальную ссылку на сделку вида https://t.me/ваш_бот?start=UUID.

Покупатель переходит по ссылке, видит детали сделки и нажимает «Оплатить с баланса».

Если баланс достаточен, средства списываются с покупателя и зачисляются продавцу, сделка завершается, продавцу увеличивается счётчик успешных сделок.

Реферальная ссылка – каждый пользователь может приглашать других, но подсчёт пока не реализован.

Смена языка – доступна в главном меню.

---

Для администраторов

Администраторы видят дополнительное меню с кнопками:

Просмотр сделок – список всех активных сделок с ID, суммой, описанием, продавцом и покупателем.

Изменить баланс пользователя – ввести ID_пользователя новый_баланс.

Изменить успешные сделки – ввести ID_пользователя новое_количество.

Изменить валюту – ввести новое название валюты (например, USD, BTC). Меняется глобально для всех.

Управление администраторами – просмотр списка, добавление нового по ID, удаление существующего (нельзя удалить себя).

⚙️ Настройка

Первый администратор – по умолчанию ID 1805496851. Измените в коде (строка с INSERT OR IGNORE INTO admins) перед запуском, если хотите другого.

Валюта по умолчанию – TON. Можно сменить через админ-панель или изменить переменную VALUTE в коде.

Путь к фото – в стартовом сообщении используется ссылка на картинку (https://postimg.cc/8sHq27HV). Вы можете заменить на свой URL или локальный файл.

Комиссия – в коде комиссия не реализована, хотя в тексте упоминается 2%. При желании можно добавить логику вычета в pay_from_balance.

📊 База данных

Таблицы:

users – user_id, wallet (текст), balance (REAL), successful_deals (INT), lang (текст).

admins – user_id.

deals – deal_id (текст, UUID), amount (REAL), description (текст), seller_id (INT), buyer_id (INT).

---

⚠️ Важные замечания

Безопасность – не публикуйте bot.log и bot_data.db в репозитории. Добавьте их в .gitignore.

Обработка ошибок – все исключения логируются в bot.log, пользователю выводится общее сообщение.

FloodWait – бот не обрабатывает ограничения Telegram, но при интенсивном использовании могут возникнуть задержки.

Тестирование – администраторы имеют бесконечный баланс, что удобно для проверки функционала.
